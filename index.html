CSS Box Model Inspection

Understanding Content, Padding, Border, and Margin

Box 1: Content Box

This box uses content-box. Padding and border are added to the specified width.

Box 2: Border Box

This box uses border-box. Padding and border are included within the specified width.

Box 3: Custom Box

This box has different padding, border, and margin values to demonstrate spacing.

Parts of the CSS Box Model

Content: The text or image inside an element.

Padding: Space between content and border.

Border: The line surrounding the padding and content.

Margin: Space outside the border.
